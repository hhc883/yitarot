- 生产构建复跑通过；首次在编译、类型检查与页面生成完成后被 Next.js 安全提示中止。框架依赖未改，发布前仍需处理并重新验证。定向 ESLint 和 `git diff --check` 通过。
- Chromium 中英文各测 320／390／1440 CSS px：从塔罗专厅实点三条路径、浏览器返回、页面返回链接和直接访问均通过。每周入口标题与目的页一致；首屏标题未被页头覆盖，页面无横向溢出。
- 是／否：示例填写、留空、抽牌、键盘翻面和重抽通过。爱情：用方向键选择情境，抽出三张牌，能够键盘翻牌并返回选择。每周：自动发五张，键盘切换主题更新解读，重抽和刷新回到第一项，无首屏渲染报错。
- 三条工具的抽牌、判断和解读均在本地完成；未产生工具 API 请求。站点通用导航的登录检查用本地 401 模拟。英文缺译的补充牌义折叠并标明为中文，没有把服务器端大阿卡纳详情打包进工具。
- 另回归中英文首页、两个专厅和专厅主入口：原生滚动、键盘锚点及无 JavaScript 的锚点都通过。本轮未测真机 Safari、线上性能或真实账号。
