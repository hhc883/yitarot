# 黄历择日 · 第一版

在东方专厅增加 `/[lang]/east/almanac`，支持中文、英文和旧专厅正常返回。基线 `a4ac9cf`，保留同一工作区此前的奇门排盘升级。

| 用途 | 检查现有历法库的传统条目 |
|---|---|
| 搬家 | 入宅、移徙 |
| 开业 | 开市 |
| 签约 | 交易、立券（传统近似条目） |

查询按公历日期，结束日包含在内，范围 1–31 天。只有宜条目命中归为「可考虑」，两边都有命中归为「有条件」，只有忌条目归为「慎用」，未命中归为「未列明」。不把值日干支、建除或冲生肖当作额外评分；不收集参与人生辰、不调用 AI 或第三方排盘接口。

数据使用项目现有 [lunar-typescript](https://github.com/6tail/lunar-typescript) 库的每日宜忌数据，页面和分类规则独立实现。先保留真实安排的优先级；黄历是民俗参考。运行回归：`node --test scripts/test-almanac.mjs`。
