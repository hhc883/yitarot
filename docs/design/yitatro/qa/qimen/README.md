# 奇门遁甲排盘升级

基线：YiTatro `a4ac9cf`。入口为 `/[lang]/east/qimen`；旧 `/[lang]/fatemaster/qimen` 继续重定向。东方专厅保留原卡片，文案同步说明采用北京时间。

本版使用时家转盘拆补，固定北京时间 UTC+08:00，不带历史夏令时或真太阳时校正，23:00 换日，中五寄坤二、天禽随天芮。以现有 `lunar-typescript` 给出的交节时刻确定当令节气，按传统局数表定局；手动输入范围 1900–2100。页面显示阴阳遁、局数、上中下元、四柱、值符和值使落宫，可键盘选择九宫。算法在本地工具页运行，不请求命语服务，不新增项目依赖。

局数、符头和排盘规则参考[《奇门遁甲统宗》](https://zh.wikisource.org/wiki/奇門遁甲統宗)。命语只用于从已有公开固定样例比对结果，未复制其实现。飞盘、置闰和终身局不在本版范围内。

运行：`node --test scripts/test-qimen.mjs`。重点覆盖芒种阳六局、夏至瞬间、23:00 换日、输入验证和跨设备时区一致性。
