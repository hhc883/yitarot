- 梅花易数：从专厅进入，检查空问题提示；实走当前时辰与自选数字，指定第六爻后核对结果，验证旧地址直达。
- 塔罗牌阵：六种牌阵均有本地化标题、说明、适用场景及牌位。从目录进入凯尔特十字和「是／否」会预选对应牌阵；仍能手动更换，无参数及无效值使用原默认。
- 每日一牌：同一天刷新保留原牌。随机重抽后返回原牌；中英文最新产物复测「开始重抽后立即返回」，原牌不被旧计时覆盖，按钮仍可用。
- 太阳、月亮、愚人有英文牌义正文和关键词。其他卡牌保留中文解读并标明语言状态。详情页标题的品牌已改为 YiTatro；站点级语言和域名待处理。每日一牌复用三张牌的译文，其余有中文提示。
