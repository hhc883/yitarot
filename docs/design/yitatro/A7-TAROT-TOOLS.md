# A7 · 塔罗专厅的三条工具路径

状态：本地验收通过，见 [A7 验收与截图](qa/a7/README.md)。Antigravity 因地区限制未实施，经用户同意由另一编码 Agent 完成，Codex 独立验收。

## 范围

三条工具只改 `src/app/[lang]/yes-no/page.tsx`、`src/app/[lang]/love/page.tsx`、`src/app/[lang]/fortune/weekly/page.tsx` 以及 `src/components/tarot/` 下的 `YesNoWidget.tsx`、`LoveTarotWidget.tsx`、`WeeklyTarotWidget.tsx`。修改路由前读本仓库的 Next.js 本地文档。以塔罗专厅、自由抽牌和每日一牌为视觉参照，复用 `TarotCardView` 的语言选项。

- 三页均提供返回塔罗专厅的本地化链接，标题说明用途，主操作清楚可见。表单、加载、选中、结果和重抽采用中性黑白、细线边框与同一文字层级，保留塔罗原画。320 px 可用；不改首页的太极开屏和上滑。不加依赖、GSAP、Lenis 或新的动效。
- 是／否：问题可选，输入有可关联的标签，保留示例填写、单张抽牌、现有判断规则和重新开始。结果用文字说明判断，不依赖颜色。
- 爱情：可用键盘切换情境，保留三张牌、对应角色和原有结果规则。保留重抽；若保留翻牌过渡，支持减少动态并清理计时器。
- 每周：保留自动发五张、五个原有主题和重新洗牌。首屏先用稳定内容，浏览器启动后再抽牌，避免服务端和浏览器独立随机造成界面不一致。主题用原生按钮，暴露选中状态。重抽回到第一项，不引入日期锁定。
- 单独修改 `src/app/[lang]/west/page.tsx` 中指向每周塔罗的卡片文案，保留其他已有改动。当前标题是「周运 · 月运 · 年运」／「Periodic Forecasts」，点击却只到 `/[lang]/fortune/weekly`。改为「每周塔罗」／「Weekly Tarot」，说明从五个主题看未来一周，按钮用「查看本周」／「View weekly spread」。验收时核对卡片、目标页和返回链接；不把月运、年运加入本批。
- 保留现有路由、业务数据、权限和积分行为。英文页使用现有英文牌名与内容；仅有中文的补充解读要明确标识或不在英文页显示。不要虚构译文，不把全套牌义正文引入客户端。

## 验收

先核对改动仅涉及六个工具文件及专厅一张入口卡的文案，再跑定向 ESLint、生产构建和浏览器测试。在中文和英文的 320／390／1440 CSS px 下，从塔罗专厅点进、返回并直达三页。分别验证是／否示例与留空抽牌、爱情情境切换及结果、每周的五项选择与重抽刷新；检查首屏标题、键盘、横向溢出、浏览器初始渲染报错和意外 API 请求。在统一的生产构建下截图，移动真机和线上性能单独记录。
