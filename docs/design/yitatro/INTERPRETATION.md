# 解读依据与验收

改动任何解卦、解牌、命盘解读或追问时，以六爻的「重建盘面 → 检索依据 → 核对引文」为参照。每个模块使用自己的流派、资料和计算方法。

1. **核对实际输入。** 从本次爻线、排盘数据、抽牌顺序与牌位重建盘面。API 使用服务端词表查出的牌名、卦名和牌义。历史记录缺少牌位或时辰时，按现有信息展示，并注明缺失项。
2. **记录资料。** 规则和文献应能定位到书名、章节、条目或仓库数据。表中写清使用的流派、译文或转述。自定义牌阵和计算口径分别注明。六爻查看 `src/lib/metaphysics/iching.ts`、`src/lib/kb` 和 `src/app/api/east/liuyao/route.ts`。Rider–Waite–Smith 塔罗使用 `src/lib/tarot/waite-basis.ts` 的对应单牌和正逆位资料。
3. **用依据约束解读。** 把盘面事实、资料释义和基于问题的推论标清。每条具体判断都要和实际输入、规则及出处对应。资料无法支持现实结果、应期、百分比或他人心理时，写明范围。演示盘明确标「示例」，页面和 API 的真实结果都执行同一要求。
4. **验证降级与追问。** 模型不可用或出处无法核验时，仍可返回实际盘面与已有依据，标明当前只提供资料说明。追问使用原盘和已验证资料，模型上一次输出只作上下文。
5. **验收。** 至少用两组能产生不同盘面的输入核对结果，再测试一组缺失资料或模型不可用的输入。核对来源链接、计算口径、显示语言和历史会话。对照原始资料查验受影响的确切条目。

塔罗的历史牌义来源为 A. E. Waite 的《The Pictorial Key to the Tarot》第三部第 2–3 节，圣杯二逆位另见第 4 节。该来源记录传统解读，站内问题引导和牌阵定位应独立标明。[历史文本](https://en.wikisource.org/w/index.php?title=The_Pictorial_Key_to_the_Tarot/Part_3&oldid=15274510)
