### 【模块一：核心断法通则（Rules，精选 35 条）】

#### Rule 01：装头测法（神龙见首）
- **【适用门类】**：通论 / 隐谋 / 功名
- **【触发盘面条件】**：来字端整但首部潜藏，如字缺上端笔画（如“戊”字见头成“茂”，“里”加立成“童”，“兄”加点成“克”或“况”）。
- **【核心断语与易理】**：字从太极出，各具首尾。其所问之事与所写之字虽隐露吉凶，而首犹藏匿，如神龙不见首；占者添笔于其上而出之，字理全彰。凡问前程遇冠带之笔，加其头而事显。
- **【应期推法】**：以所添部首所应之天干地支或时令节气（如春日见草头）定应期。

#### Rule 02：接脚测法（基址步履）
- **【适用门类】**：出行 / 胎产 / 根基
- **【触发盘面条件】**：来字形体已现但下部未全，如人之身已现而未举足行动（如“立”接脚为“产”或“童”，“自”接脚为“息”或“身”）。
- **【核心断语与易理】**：字如人之体，有冠必有履。察其善恶，下部承载有力则根基稳固；下虚悬空则步履维艰、浮萍无根。问产见“立”接脚为“产”，主立时分娩。
- **【应期推法】**：视接脚所成之字底步履迟速，逢冲逢值之日举步。

#### Rule 03：穿心测法（中缝穿针）
- **【适用门类】**：灾厄 / 忧患 / 阻隔
- **【触发盘面条件】**：字画端正、左右对称俱全，而从中有一竖穿入（如“文”穿心成“吏”，“昌”穿心中成“量”，“月”穿心成“用”或“舟”）。
- **【核心断语与易理】**：凡字如衣裾之缝，中穿一笔则破其中和。心受穿刺，主忧心忡忡、暗疾缠身、事起萧墙；若为文人得穿心化“吏”，反为入仕典刑之象。
- **【应期推法】**：穿心之难解于穿笔受冲受克之期。

#### Rule 04：包笼测法（罗网围裹）
- **【适用门类】**：狱讼 / 藏匿 / 资财
- **【触发盘面条件】**：字之全体不动，而从周围加框廓包裹之（如“贝”包成“遗”，“玉”包成“宝”，“由”包成“遭”）。
- **【核心断语与易理】**：全体被笼，如入罗网，亦如入库藏。问罪狱逢包笼，主深陷囹圄，插翅难飞；问求财逢包笼，主外人圈套暗算，或财帛入瓮归仓。
- **【应期推法】**：破局出壳待冲破外围之日月。

#### Rule 05：破解测法（劈破解拆）
- **【适用门类】**：散析 / 争端 / 疾病
- **【触发盘面条件】**：将字之体段劈开，从中抉出笔画或旁分各字（如“行”破为“术”与“衙”，“合”拆为“人、一、口”，“程”拆为“禾、呈”）。
- **【核心断语与易理】**：“破易而解难，破平正而解奇幻”。字合则聚，字破则散。问病见字破主解脱或骨肉分离；问合伙见破解必分家各走。
- **【应期推法】**：拆出各偏旁所含干支五行衰旺之期定之。

#### Rule 06：添笔测法（损益补足）
- **【适用门类】**：通论 / 补益
- **【触发盘面条件】**：字显残缺不全，需增添笔画以尽其变（如“唯”添笔为“难”，“合”添笔为“命”，“王”添笔为“玉”或“旺”）。
- **【核心断语与易理】**：邵康节曰：“当添亦添，当减亦减”。添乃补其不足，损益相兼。问求官见“王”添一点成“玉”，主加官进禄；问灾咎添笔成凶字者祸不单行。
- **【应期推法】**：所添之笔化合生旺之期应验。

#### Rule 07：减笔测法（削去繁芜）
- **【适用门类】**：消灾 / 破耗 / 归隐
- **【触发盘面条件】**：字形太繁、过盛，略削一二笔以显真机（如“宽”减为“见”，“莫”减为“草”）。
- **【核心断语与易理】**：减笔非理之正不可漫用，唯字形亢盛而问退步、削籍、消灾时用之。凡盛极减笔，去其病根；若问财遇减笔，主破耗耗散。
- **【应期推法】**：以削去之笔画五行受克绝之时定局。

#### Rule 08：对关测法（开阖门户）
- **【适用门类】**：谋事 / 离合 / 出入
- **【触发盘面条件】**：专取字之头足首尾。分开为门之开，合之为门之闭（如“先”为牛头虎足，“善”为美头喜足，“帛”为皇头帝足，“里”为男头童足）。
- **【核心断语与易理】**：此测字第一简捷要义。关门则事阻秘匿，开门则任人出入。首尾相顾者终始如一，首尾背离者半途翻覆。
- **【应期推法】**：头尾两字地支逢合逢冲之时应事。

#### Rule 09：摘字测法（抽梁换柱）
- **【适用门类】**：突发机兆 / 奇变
- **【触发盘面条件】**：借字中细微笔画单独抽出断事（如“哉”摘取“土”与“戈”，“殿”摘取“共”）。
- **【核心断语与易理】**：事机偶到，不仅万物声影可借，字中之偏旁琐笔亦可单提。字大而取其微，见微知著，祸福全在一发之间。
- **【应期推法】**：以所摘单字或笔画五行逢长生帝旺之时决断。

#### Rule 10：观梅测字（心镜洞照）
- **【适用门类】**：心易触机 / 极变
- **【触发盘面条件】**：借来测之时天时、地利、人事、方位及来者声色体态。
- **【核心断语与易理】**：心镜光明，随物洞照。有物之字推其物理，无物之字察其来机与到时之影响。字虽凶而外应吉，减凶添庆；字虽吉而外应折，化吉为悲。
- **【应期推法】**：随外应之动态迟速（行应速、坐应迟、走愈速、卧愈迟）。

#### Rule 11：象形测法（以形体貌）
- **【适用门类】**：测病 / 测形 / 物理
- **【触发盘面条件】**：字形肖物，或物形肖字（如“乙”似鱼钩，“弓”似蛇，“亚”似纱窗，“身”似皂隶）。
- **【核心断语与易理】**：见字如见形。问病见“弓”主蛇精入体或肠腹盘结；问捕鱼见“乙”下竿必得；见“门”无栓如张虚口。
- **【应期推法】**：无特定义规，视象形物类所值时令断之。

#### Rule 12：会意测法（体认事理）
- **【适用门类】**：谋望 / 事机成败
- **【触发盘面条件】**：不拘笔画，全凭字面意境融通（如“烟”为因风吹火，事必借力；“淋”为楚汉争锋，主有口角是非；“霏”为长虹截雨，多阻隔）。
- **【核心断语与易理】**：因意生象，因象定理。事之所寄，全含字意。遇“居”如跋胡疐尾，进退不得自如；遇“裕”如补天浴日，必得大人维持。
- **【应期推法】**：依会意情景所指时节为期。

#### Rule 13：假借测法（乾坤挪移）
- **【适用门类】**：四时 / 人事
- **【触发盘面条件】**：字借为四时、人事之用（如“旦”借为春，“千”借为夏，“甲”借为秋，“夕”借为冬；“立”遇人借为位，遇水借为泣）。
- **【核心断语与易理】**：阴阳假合，转借通微。“口”见鸟过借为鸣，见木过借为困中。随来机借用，借得真神，如虎添翼。
- **【应期推法】**：以所借四时方位及干支为定。

#### Rule 14：谐声测法（声律吉凶）
- **【适用门类】**：闻声 / 言语
- **【触发盘面条件】**：利用同音假借（如“倒”同“到”，“秤”同“称”，“梨”同“离”，“桃”同“逃”）。
- **【核心断语与易理】**：耳之所受，音通造化。“莺”问晴雨，因莺与阴同音，断天必阴晦；问病书“康”，入木无疑；问分娩书“茄”，加子可喜。
- **【应期推法】**：按谐声音律所发时刻断。

#### Rule 15：转注测法（平去异音）
- **【适用门类】**：吉凶翻转
- **【触发盘面条件】**：一字多音，平声与去声之转（如“临”作去声为临丧，“王”作去声为旺相，“为”作去声为作为）。
- **【核心断语与易理】**：机随声变。临字问病，读去声则断曰临丧大凶；王字问求财，读去声则断曰大旺大吉。神机在口，出音定局。
- **【应期推法】**：以转声音度所值五行论期。

#### Rule 16：指事十法总纲（相字根本）
- **【适用门类】**：心易总纲
- **【触发盘面条件】**：占断时观人、察色、辨言、辨事、察墨、辨纸、观时、相机、正论勿好奇、言语不可杂。
- **【核心断语与易理】**：字非死物，随人赋形。字好人俗不可断吉，字丑人清当知发越；浓墨中间薄似云防暗算，淡墨点滴如流泪主哭泣。正论为本，怪诞勿取。
- **【应期推法】**：十法交参，极速定应。

#### Rule 17：五行生克配字画（正五行骨格）
- **【适用门类】**：通论 / 五行
- **【触发盘面条件】**：字画分木（直）、火（尖撇）、土（横厚）、金（圆方刚）、水（弯浪流）。
- **【核心断语与易理】**：凡横画多为土，直画多为木，撇捺尖挑为火，圆圈转角为金，波浪点滴为水。木字见金克，折木受伐；金字得土生，出土宝镜；水多火熄，土厚水干。
- **【应期推法】**：字中生克双方旺相休囚之月令。

#### Rule 18：字中六神隐现察机（六神动静）
- **【适用门类】**：通论 / 辅助取象
- **【触发盘面条件】**：字中见青龙、朱雀、勾陈、螣蛇、白虎、玄武之形。
- **【核心断语与易理】**：青龙喜气丰亨，朱雀飞扬口舌官非，勾陈迟滞田土争端，螣蛇惊怪萦绊，白虎血光刀刑，玄武阴私盗窃。字见白虎脚加刀刃，大凶受刑。
- **【应期推法】**：六神所值之日辰定事。

#### Rule 19：字同事不同，倏变吉而变凶
- **【适用门类】**：通论 / 变通至理
- **【触发盘面条件】**：不同人同书一字，或一人以一字问数事。
- **【核心断语与易理】**：邵子曰：“字同事不同，不宜此而宜彼；事同字不同，倏变吉而变凶”。来者身份、时空、问事皆殊，机栝大异。如“火”字商贾问行商大吉，病者问体热焚身立毙。
- **【应期推法】**：随时空生克具体判定。

#### Rule 20：奇偶笔画定乾坤男女
- **【适用门类】**：胎产 / 功名
- **【触发盘面条件】**：计来字之总笔画数，或偏旁笔画之奇偶。
- **【核心断语与易理】**：奇数为阳，主生男、主贵、主进；偶数为阴，主生女、主静、主退。同一“元”字，三笔写成（奇数）断生男，四笔写成（二横平架如桥为偶数）断生女。
- **【应期推法】**：奇逢阳日产男，偶逢阴日产女。

#### Rule 21：偏旁带水，功名源远与浮沉
- **【适用门类】**：功名 / 身命
- **【触发盘面条件】**：来字带“氵”旁。
- **【核心断语与易理】**：水主流通润下。得旺相之合如“江”为功名源远，“沆”为龙归沧海；若遇休囚之字如“沐”为一木浮沉，“沈”为泪沾绣枕，“汉”为临河望洋兴叹。
- **【应期推法】**：旺在秋冬坎水之月，绝于春夏。

#### Rule 22：偏旁带火，文彩辉煌与焦头烂额
- **【适用门类】**：仕宦 / 疾病
- **【触发盘面条件】**：来字带“火”或“灬”。
- **【核心断语与易理】**：火主文明、光明。得位如“耿”为所取最美，“烹”为调和鼎鼐；失位受克如“烦”为焦头烂额，“煤”为谋救燃眉，“烟”为风吹火灭。
- **【应期推法】**：旺在巳午夏令，冬水临之熄灭。

#### Rule 23：偏旁带金，破镜分钗与名重金瓯
- **【适用门类】**：求财 / 婚娶
- **【触发盘面条件】**：来字带“金”旁。
- **【核心断语与易理】**：金主坚刚裁断。得吉神如“钟”为名重金瓯，“钰”为堆金积玉；遇凶格如“金”为破镜分钗，“钱”为金气摧残杀气逼身。
- **【应期推法】**：秋季金旺应吉，夏火熔金受损。

#### Rule 24：偏旁带木，栋梁高折与枯槎入海
- **【适用门类】**：功名 / 产业
- **【触发盘面条件】**：来字带“木”旁。
- **【核心断语与易理】**：木主发生条达。得运如“橙”为登科夺标，“桂”为蟾宫折桂，“槐”为榜上经魁；见衰绝如“枯”为故旧相辞，“林”为一火焚之，“机”为树静风不息。
- **【应期推法】**：春令条达，秋金当令摧残。

#### Rule 25：偏旁带土，高台既倾与万物有基
- **【适用门类】**：田土 / 家宅 / 寿夭
- **【触发盘面条件】**：来字带“土”旁。
- **【核心断语与易理】**：土为万物之母，镇静持重。得位如“境”为宝镜重光，“坐”为有人有土；失位逢凶如“至”为高台既倾，“埋”为理上有亏，“土”为坐上无人敲断玉钗。
- **【应期推法】**：辰戌丑未四季土旺之日。

#### Rule 26：偏旁带竹，清闲节操与管弦喧闹
- **【适用门类】**：仕途 / 婚庆
- **【触发盘面条件】**：来字带“⺮”头。
- **【核心断语与易理】**：竹乃清高直节之物。“等”为及时献策，“算”为算头不浅，“篝”为讲究策论；然问俗名利禄，寺竹多主清闲孤寡，或吹箫奏乐逢虚花。
- **【应期推法】**：逢春水滋荣，遇秋金断节。

#### Rule 27：偏旁带草，芳华繁茂与落叶辞柯
- **【适用门类】**：家道 / 财禄
- **【触发盘面条件】**：来字带“艹”头。
- **【核心断语与易理】**：草木繁华瞬息。得吉如“满”为时雨滋苗，“荣”为金谷繁华；遇凶如“荒”为水流花谢，“落”为草泽之客藏头露尾，“草”为不能成章。
- **【应期推法】**：春夏生机蓬勃，霜降百草枯凋。

#### Rule 28：偏旁带门，开合无常与双泪流干
- **【适用门类】**：门户 / 词讼
- **【触发盘面条件】**：来字带“门”或“户”。
- **【核心断语与易理】**：门主出入通塞。“开”为公门刑罚，“闪”为人入空门，“间”为门迎百福；“戾”为双泪流干，“闭”为大限闭塞。冬令门闭，春令门开。
- **【应期推法】**：冲开门栓之日，或开门出入之月。

#### Rule 29：偏旁带心，愁肠百结与福到心灵
- **【适用门类】**：忧患 / 性情
- **【触发盘面条件】**：来字带“心”或“忄”。
- **【核心断语与易理】**：心为一身之君。“恩”为烟尽火灭，“忠”为意外之患，“愁”为得意之秋，“志”为悲喜交集；若心中带刺、穿心带戈，心神不宁。
- **【应期推法】**：心火当权逢巳午月日，或水制心火之期。

#### Rule 30：偏旁带言，谗谤陷人与一诺千金
- **【适用门类】**：词讼 / 考校
- **【触发盘面条件】**：来字带“言”旁。
- **【核心断语与易理】**：言为祸福之门。“诗”为翰林待诏维持众论，“词”为未同而言；“谄”为以言陷人，“该”为言辞刻薄；问病见“言”多主不治（人将死而言善）。
- **【应期推法】**：言发之日，或朱雀逢合逢冲之时。

#### Rule 31：字带戈戟刀刃，横祸受制
- **【适用门类】**：词讼 / 仇杀 / 军旅
- **【触发盘面条件】**：字中见“刂”、“戈”、“斤”、“矛”。
- **【核心断语与易理】**：兵器出鞘，肃杀逼人。武职见之位登元戎，文人见之削职除名；问身家见刀戈加身，大难临头，若非刑网必遭血光。
- **【应期推法】**：逢白虎生旺、金刃当值之秋月申酉日。

#### Rule 32：字见残缺断头，凡事半涂
- **【适用门类】**：通论 / 寿命
- **【触发盘面条件】**：来字笔画脱落、断头折足（如“夫”断头成“天”或“失”）。
- **【核心断语与易理】**：字如人之体，头断则亡，足折则蹶。问功名断头无顶冠，问病断头命难全；断足者行人不归，事体中途搁浅。
- **【应期推法】**：绝笔所值干支逢绝墓之期归空。

#### Rule 33：字形端正清奇，富贵之征
- **【适用门类】**：功名 / 终身
- **【触发盘面条件】**：来字笔迹停匀、浓淡适中、骨肉相称、神采奕奕。
- **【核心断语与易理】**：字乃心画，字品即人品。字形端整昂藏者，虽在贫贱终成大器；字带台阁之气（如“宫”、“宣”、“台”），官登极品。
- **【应期推法】**：逢交鸿运之流年太岁生扶之期发越。

#### Rule 34：同字重来，先发为退，后书为进
- **【适用门类】**：较量 / 竞争
- **【触发盘面条件】**：二人同书一字，或前后以同一字相问。
- **【核心断语与易理】**：先占者事已露，气运向退；后占者方兴未艾，气机方盛。如二人皆以“火”字问前程，先者乃退火，后者乃方兴之烈火，后人必胜于前人。
- **【应期推法】**：前人应在退气之时，后人应在乘旺之期。

#### Rule 35：动静向背，吉凶从聚散
- **【适用门类】**：通论 / 机括
- **【触发盘面条件】**：察字之笔势往来、开合、向背。
- **【核心断语与易理】**：笔势相向而来，吉喜将至；笔势相背而去，恩义已绝、祸福已过。向我者事易就，背我者人情散淡，任使千金难挽回。
- **【应期推法】**：向背转关之日月为定局。

- **【占问事项与主体】**：一人问妻子分娩六甲。
- **【核心用神与推演分析】**：“欠”字加两点为“次”，故断决非首胎，乃第二胎；“欠”字加土为“坎”，坎为中男，故知必生男儿；初十来占，加十一在旁亦成“坎”卦，故知次日（十一日）必顺产。
- **【实际应验结果与时间】**：次日（十月十一日）果产下一男，且其家确为生次子。

- **【核心用神与推演分析】**：钱乃外圆内方，地天交泰之象；倒指顺字为“手到即顺”，婚姻早定必成；然钱乃外实内虚、中有方孔之物，资财不多；且“顺”字从三笔起、“愿”字结局，得利仅三分。
- **【实际应验结果与时间】**：婚姻谐和；贩货归来盘账，果然仅获三分微利。

#### Case 26：寅字问圣驾行期，宇宙一人二月七日驻跸
- **【时空与盘面数据】**：正月初八。指通书上月建“寅”字。

- **【核心用神与推演分析】**：“寅”乃宇宙一人之字，上带离火之尊，下有甲胄之士拥卫；寅属阳木，必待水生木之月日到达。
- **【实际应验结果与时间】**：二月初七（壬午水日）圣驾果驻跸维扬行宫。

#### Case 27：公字问合伙，分字头去字脚成讼
- **【时空与盘面数据】**：某日。书“公”字。

- **【实际应验结果与时间】**：其人遵嘱息争，次年表兄和颜相商，和平析产自开分店。

#### Case 28：求财二字问行商，东南买果西北亏折
- **【时空与盘面数据】**：客不写字，程省直取其口称之“求财”二字。

- **【实际应验结果与时间】**：其客此前贩洞庭木瓜至淮北腐烂折本，本次重贩果然尽获丰利。

#### Case 29：子字童字问婚讼，赠财代聘两得安全
- **【时空与盘面数据】**：某日。先后书“子”字与“童”字。

#### Case 30：衡字问夜行客，丁亭止步明晨并至
- **【时空与盘面数据】**：灯下。吴友书“衡”字。

#### Case 31：芍字问产后少妇，花残月缺豹尾丧命
- **【时空与盘面数据】**：某日。书“芍”字。

#### Case 32：磨字问山地风水，历头磐尾大发解元

#### Case 33：飒字同字三人问，机变三端应期各异
- **【时空与盘面数据】**：三人先后同书“飒”字问行人归期。
- **【占问事项与主体】**：三客问远方行人何时归。
- **【核心用神与推演分析】**：

- **【实际应验结果与时间】**：第一客出门即遇行人；第二客先收书信后半月归；第三客果于三日后辛卯日抵达。

#### Case 34：投字问岁考，秀才受扑责降四等

#### Case 35：纸字问山向风水，纺绩终氏多出孤寡

### 【模块三：独门象意概念（Concepts）】

《测字秘牒》将汉字从先秦六书象形表意功能，升华为一套沟通宇宙全息易象的**“汉字全息字典库”**：

#### 1. 偏旁部首全息取格类象
程省在卷三《测字取格大法》中，开创了以五行偏旁为纲领的取象定性格局：
- **氵（水部类象）**：
  - *吉格物象*：江（功名源远）、沆（龙归沧海）、沛（雨露沾濡）、涵（包容大度）、海（海纳百川）。
  - *凶格物象*：沐（一木浮沉）、沈（泪沾绣枕）、汉（临河兴叹）、池（平地兴波）、漏（云泥之隔）。
- **火 / 灬（火部类象）**：
  - *吉格物象*：耿（所取最美）、烹（调和鼎鼐）、焦（佳人燕喜）、熙（景星庆云）。
  - *凶格物象*：烦（焦头烂额）、煤（谋救燃眉）、烟（风吹星散）、黑（墨突不黔）。
- **金 / 钅（金部类象）**：
  - *吉格物象*：钟（名重金瓯）、钰（堆金积玉）、锐（囊锥脱颖）、铸（千金上寿）。
  - *凶格物象*：钱（金气摧残）、银（钱粮不足）、钗（破镜分钗）、钞（披沙拣金）。
- **木（木部类象）**：
  - *吉格物象*：橙（登科夺标）、桂（蟾宫折桂）、槐（榜上经魁）、栋（东风拂柳）。
  - *凶格物象*：枷（跌倒架子）、枯（故旧相弃）、朽（巧尽成空）、村（求荣反辱）。
- **土 / 阝（土石城基类象）**：
  - *吉格物象*：境（宝镜重磨）、坐（有人有土）、坤（安贞厚德）、域（跨海封疆）。
  - *凶格物象*：至（高台既倾）、埋（理上有亏）、垣（萱堂有损）、坊（半途崩折）。

#### 2. 字画骨骼散格系统（人体与造化结构对应）
卷五《测字散格法》确立了以字之各部位对应宇宙人身之立体骨骼：
- **字之“头”（冠冕·上司·父母·天心）**：
  - 如“先”之上为“牛头”、“美”之上为“羊头”、“家”之上为“守头”；头正心公，头欹案斜。
- **字之“心”（神明·腹臆·妻室·主宰）**：
  - 如“思”以“田”为良心，“忠”以“中”为正心；穿心见刺，必罹内患。
- **字之“身”（自身·骨骼·事业·居室）**：
  - 如“身”如皂隶，“用”如闭门；身体端凝者基业雄厚，身体歪斜者行藏诡诈。
- **字之“足”（步履·子息·根基·归宿）**：
  - 如“先”之下为“虎足”，“善”之下为“喜足”，“立”之下为“产足”；足动者有行，足削者中途夭蹶。

#### 3. 笔形五行与六神体用
- **木笔（直画长秀）**：主仁和、生发、秀拔；折断带刺者主筋骨之疾。
- **火笔（撇捺尖挑）**：主文章、光烈、焦燥；重见双挑主口舌火烛。
- **土笔（横画厚重）**：主田土、安稳、迟滞；断绝空亡主家宅倾颓。
- **金笔（方正圆转）**：主断制、刑威、钱财；尖锐露锋主刀兵杀伐。
- **水笔（波浪点滴）**：主流通、聪明、潇洒；拖泥带水主流离涕泣。

#### 4. 相字至理八法神机
- **以字象物**：口如方匣，乙如鱼钩，亚如纱窗，了如悬索。
- **借字谐声**：借同音之响，断幽微之事（如见鹿即断禄，见蜂即断封）。
- **动静克应**：耳听笑语吉庆临门，目睹器缺谋为必毁；行测速到，坐问迟来。
- **正论勿好奇**：测字乃依经入史之儒门正易，先察五行八卦理气，切忌矜奇弄巧、流于诞妄。
