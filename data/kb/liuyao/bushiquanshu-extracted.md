#### Rule 01：生克权舆归于日月
- **【适用门类】**：通论
- **【触发盘面条件】**：月建、日辰入卦或临爻。
- **【核心断语与易理】**：月建为万卜之提纲，日辰为一日之主宰。“日伤爻，真罹其祸；爻伤日，徒受其名”。爻之衰弱休囚者，日月能生之扶之；爻之旺相发轫者，日月能克之挫之。日辰能冲起静爻（暗动），能冲散动爻，能冲实空亡，克破墓库。
- **【应期推法】**：用爻休囚，以生旺月日断；动爻逢合，以冲开之日断；爻被合住，以冲破克破之日断。

#### Rule 02：无故自空与避凶而空
- **【适用门类】**：通论 / 凶危
- **【触发盘面条件】**：爻落旬空，分为“无故自空”与“有故而空”。
- **【核心断语与易理】**：卦爻无刑冲克害，而用神、世身自落空亡，谓之“无故自空”，大凶之兆，占病必死，谋事终不成；若爻受日月动爻重克刑冲，而恰值空亡，谓之“避凶而空”（避之则吉），待出空之日免祸成事，过旬即用。
- **【应期推法】**：假空者出旬逢值逢冲之日应验；真空者到底成空无应期。

#### Rule 03：动为事之始，变为事之终
- **【适用门类】**：通论 / 动变
- **【触发盘面条件】**：卦爻发动化出变爻。
- **【核心断语与易理】**：动爻为谋事之始基，变爻为归宿之终局。最怕“动变交争”与“化回头克”；动爻虽旺，若变爻化出死、墓、绝、空或回头冲克，始吉终凶；动爻虽困，若化长生、帝旺、回头生，始难终吉。
- **【应期推法】**：事应在变爻所值地支之生旺逢值逢冲之期。

#### Rule 04：进神退神之动变定序
- **【适用门类】**：通论 / 谋望
- **【触发盘面条件】**：寅化卯、巳化午、申化酉、亥化子、丑化辰、辰化未、未化戌、戌化丑（进神）；反之为退神。
- **【核心断语与易理】**：“动变比和，当明进退”。化进神者，其势长驱直前，久远大吉；化退神者，其力渐衰落后，占行人虽发而中途复还，占物日渐退缩。
- **【应期推法】**：进神应于逢值逢合之日；退神应于冲退退绝之期。

#### Rule 05：飞神与伏神引拔通微

- **【适用门类】**：天时阴晴
- **【触发盘面条件】**：父母爻、妻财爻、子孙爻、官鬼爻之动静旺衰。
- **【核心断语与易理】**：“当究父财，勿凭水火”。父母动狂风霖雨，妻财动万里晴明，子孙动红霞霁色，兄弟动风云闭塞，官鬼动雷电霹雳。应为天，世为地；应克世无雨，世克应甘霖倾盆。
- **【应期推法】**：占雨逢父爻生旺之日，占晴逢财爻绝处逢生之日。

#### Rule 29：年时吉凶，五爻君位初爻万物
- **【适用门类】**：年时国事
- **【触发盘面条件】**：太岁、月建入卦生克各爻位。
- **【核心断语与易理】**：初爻万物，二爻百姓，三爻县府，四爻公卿，五爻天子，六爻昊天。太岁动生世民安物阜，太岁冲克岁多灾异；金鬼动四海干戈，水鬼动江淮泛滥，火鬼动回禄肆虐，土鬼动瘟疫猖獗。
- **【应期推法】**：应期以太岁、月建所值之季度月日定之。

#### Rule 30：鬼伏有殃，鬼动成灾
- **【适用门类】**：疾病 / 隐患
- **【触发盘面条件】**：官鬼爻伏藏在不同六亲之下。
- **【核心断语与易理】**：鬼伏父母下：因房宅尊长文书起祸；鬼伏兄弟下：因争财赌博同僚构衅；鬼伏子孙下：为僧道勾连或医巫致疾；鬼伏财爻下：为饮食酒色及阴人暗害。
- **【应期推法】**：飞神受冲被制、伏鬼透出之日祸患发作。

#### Rule 31：自空化空，百无一成
- **【适用门类】**：通论 / 凶煞
- **【触发盘面条件】**：动爻本身落空，变出之爻亦落旬空。
- **【核心断语与易理】**：“自空化空，必成凶咎”。动值真空，毫无依托，如履深渊绝壁，求事断无成理，问病立见暴亡；唯忌神见之大喜，转凶为福。
- **【应期推法】**：无应期，到底成空。

#### Rule 32：六神专司情状，不可妄断吉凶
- **【适用门类】**：通论 / 取象
- **【触发盘面条件】**：青龙、朱雀、勾陈、螣蛇、白虎、玄武加临六爻。
- **【核心断语与易理】**：“六亲为本，六神为末，神杀又末中之末”。“虎兴而遇吉神，不害其为吉；龙动而逢凶曜，难掩其为凶”。白虎临用爻生世，军威大将之显贵；青龙临忌爻克世，酒色非灾之重挫。
- **【应期推法】**：吉凶归于五行生克，六神仅定情性与事物形态。

#### Rule 33：太岁入爻，吉凶关乎朝野
- **【适用门类】**：通论 / 国朝 / 功名
- **【触发盘面条件】**：流年太岁地支出现在卦爻中并动发。
- **【核心断语与易理】**：太岁乃天子之星，至尊无比，宜静不宜动。动而生合世爻，主朝廷恩诏、封诰加官；动而冲克世身，大祸临门，常人破家，仕宦削籍，一年内大凶难免。
- **【应期推法】**：冲克应在太岁逢值、逢冲之月。

#### Rule 34：两鬼两财，反复不常
- **【适用门类】**：功名 / 词讼 / 婚姻
- **【触发盘面条件】**：卦中出现两重官鬼或两重妻财同动。
- **【核心断语与易理】**：一卦见两官，政令何曾归一，事体翻腾两司，狱讼反复；占婚见两财两官，婚配乖违，重婚续弦。物多则不专，吉不能为纯吉，凶不能为全凶。
- **【应期推法】**：待一爻受克制入墓、一爻得令逢值之期始定局。

#### Rule 35：动而逢合，必待冲开之期
- **【适用门类】**：通论 / 迟速应期
- **【触发盘面条件】**：动爻被日辰合住，或动变地支相合。
- **【核心断语与易理】**：“爻逢合住，纵动无功”。凡动爻虽生克有力，若被日辰或变爻合住，为贪合牵绊，如人被绊足，无法施展；必须待冲破、克破合神之日，其机栝方能发露而吉凶应验。
- **【应期推法】**：断事应在逢冲之日、冲开之月。

### 【模块二：经典实战占验案例（Cases，全量代表性萃取）】

#### Case 01：袁柳庄卜脱役事，被日冲鬼害世难脱
- **【时空与盘面数据】**：丙子日（旬空：申酉）。天风姤（静卦）。
- **【占问事项与主体】**：明代相术大家袁柳庄自占能否免脱差役。
- **【核心用神与推演分析】**：以官鬼为役差用神。卦得天风姤，官鬼临应爻（九四壬午火）。虽六爻安静，但丙子日辰之子水直接冲动应上官鬼，官星被冲暗动；更兼子水日辰与世爻丑土相合而子水又与午火相冲克，世受六害官非相缠。原断以为世爻遭刑冲害绊，官星被冲而紧逼，断定役事难免。
- **【实际应验结果与时间】**：果应难脱官府差役，被派充当役差。

#### Case 02：谈朝辅卜诉讼，官鬼入空诉讼不成
