### 【模块一：核心断法通则（Rules）】

#### Rule 01：生克之权在日月
- **【适用门类】**：通论
- **【触发盘面条件】**：月建、日辰对卦中六爻之生克作用。
- **【核心断语与易理】**：月建、日辰为卦之纲领，司三秋之令，操万物之权。凡爻得月建生扶、日辰生扶，乃真旺相；虽遇动爻克制，亦能敌衡。爻若休囚而遭月克日刑，虽动而逢生亦如风中之烛。日月能生旺动之爻，亦能克衰绝之爻。
- **【应期推法】**：无特定义规，视生克双方之逢值、逢冲日定。

#### Rule 02：月破之真假与用神实破
- **【适用门类】**：通论 / 吉凶应期
- **【触发盘面条件】**：爻支与月建相冲（如子月见午火爻）。
- **【核心断语与易理】**：与月相冲为月破。动爻逢破，其破不深；静爻休囚逢破，乃真破也。动而逢破者，得日辰动爻生扶，逢实破、逢合之日月仍能有用；伏神逢破，出伏亦难成事。爻破而静、更值休囚受克者，谓之百无一用。
- **【应期推法】**：动爻月破，多应在出月、实破（值该爻之日月）或逢合之日；真空真破者无应期。

#### Rule 03：旬空之真空与假空
- **【适用门类】**：通论 / 应期
- **【触发盘面条件】**：爻临旬空。
- **【核心断语与易理】**：野鹤定空亡有三：动不为空，旺不为空，受日辰动爻生扶者不为空；唯有休囚无气、受克受刑、安静不动者，乃为真空。真空者到底成空，假空者出旬、逢冲之日即发。
- **【应期推法】**：旺相旬空者，应在出空之日（逢值）或冲空之日。

#### Rule 04：神兆机于动，动必有因
- **【适用门类】**：通论
- **【触发盘面条件】**：卦有爻动。
- **【核心断语与易理】**：静者以静而待，动者机括发露。一卦吉凶，全系于发卦之动爻。动爻有力，能生克他爻；动爻变出之爻，只能回头生克冲合本位动爻，不得跨越生克他爻。动化回头生者大吉，动化回头克者大凶。
- **【应期推法】**：动而逢合，应在冲开之期；动而逢冲，应在逢合逢值之期。

#### Rule 05：进神退神之动变生克
- **【适用门类】**：通论 / 进退吉凶
- **【触发盘面条件】**：亥化子、寅化卯、巳化午、申化酉、丑化辰、辰化未、未化戌、戌化丑（进神）；反之为退神。
- **【核心断语与易理】**：化进神者，如春苗得雨，其势愈增，久远吉凶不可限量；化退神者，如蚕老作茧，其势渐减，旺者退慢，衰者退速。用神化进，诸事亨通；忌神化进，大祸立至。动而化退，逢生不生，逢克减力。
- **【应期推法】**：进神应在逢值、逢合之期；退神应在实退、退绝之期。

#### Rule 06：反吟伏吟之祸福深浅
- **【适用门类】**：身命 / 官讼 / 迁徙 / 灾异
- **【触发盘面条件】**：卦见地支相冲相克之卦变（反吟）；卦爻地支不变且伏见同支（伏吟）。
- **【核心断语与易理】**：反吟主事体反复颠倒，去而复返，成而复败；内卦反吟内不安，外卦反吟外不安，内外俱反吟，家业荡然。伏吟主事体忧郁呻吟，进退维谷，如坐愁城。然反吟若用神旺相逢生，仅主反复周折，终归克定。
- **【应期推法】**：冲破逢合或逢冲开墓库之月日为定。

#### Rule 07：合处逢冲与冲中逢合
- **【适用门类】**：婚恋 / 交易 / 疾病 / 出行
- **【触发盘面条件】**：六合卦变六冲卦，或动爻作合而日辰冲之；反之六冲变六合。
- **【核心断语与易理】**：六冲主散，六合主聚。六合变六冲，先合后离，始吉终凶，结盟反目，成事化虚；六冲变六合，散而复聚，破镜重圆，官事解散，婚姻失而复得。
- **【应期推法】**：合变冲者应在冲日；冲变合者应在合日。

#### Rule 08：近病逢冲即愈，久病逢冲必死
- **【适用门类】**：疾病
- **【触发盘面条件】**：占病遇六冲卦，或用神受日辰、动爻相冲。
- **【核心断语与易理】**：近病（暴病、新病），邪气客于体，逢冲则邪气溃散，不药而愈；久病（宿疾、重病），元气亏虚，逢冲则根本动摇，神脱魄散必死。
- **【应期推法】**：近病应于冲用、冲官之日退；久病应于冲散用神、逢墓之期绝。

#### Rule 09：久病逢合必死，近病逢合绵延
- **【适用门类】**：疾病
- **【触发盘面条件】**：占病遇六合卦，或用神化合、动逢合。
- **【核心断语与易理】**：久病逢合，沉疴难拔，羁绊入地，生机闭塞必死；近病逢合，疾情牵缠，骤难除根，拖延迁延。
- **【应期推法】**：久病应于合绝受克之期；近病待冲开合神之日见轻。

#### Rule 10：随鬼入墓之真伪辨

- **【触发盘面条件】**：用神或世爻随官鬼同入日墓、动墓、变墓。
- **【核心断语与易理】**：古法重随鬼入墓，野鹤明辨：世爻或用神旺相逢生者，非真入墓，乃暂时藏匿或困顿；唯用神休囚无气，又见官鬼化墓、动爻入墓、日辰墓之，方作真凶，主受困深狱或病入黄泉。
- **【应期推法】**：真墓者逢冲墓之期难救；假墓者冲开墓库之日月脱困。

#### Rule 11：绝处逢生之复起
- **【适用门类】**：通论 / 功名 / 疾病
- **【触发盘面条件】**：用神绝于月建、日辰或动爻，而得他爻生扶；或用爻化绝而变爻回头相生。
- **【核心断语与易理】**：用神处于绝地，得动爻相生，或得日辰生扶，谓之“绝处逢生”。如木绝在申，遇亥水发动生木；金绝在寅，遇辰戌丑未动而生金。凡逢此象，凶中见吉，绝处逢生，事已垂尽而复起。

- **【核心断语与易理】**：游魂卦主人心无定向，游移四方，难以即归；归魂卦主人倦鸟思归，行人在路，速归之兆。用神动化归魂，其人必归；用神动化游魂，复又飘荡。
- **【应期推法】**：归魂卦逢冲逢值之期即见；游魂卦待变归魂逢生方有信。

### 【模块三：独门象意概念（Concepts）】

野鹤老人在《增删卜易》中对传统汉易与宋明术数的取象体系进行了大规模的批判性重构，其核心精髓是“**去枝蔓、重机理、依情断象**”，提炼出以下独门象意体系：

#### 1. 六亲实战功能取象
- **父母爻（庇护与凭证之象）**：
  - *人事取象*：父母、尊长、师保、公婆、老者、城主。
  - *物事取象*：房屋、宅舍、衙门、城池、车舟、衣服、雨具、章奏、公文、契约、照会、敕命、书信、试卷。

  - *人事取象*：官长、上司、主事、盗贼、奸细、媒妁（婚占中）。

- **兄弟爻（劫财与阻隔之象）**：
  - *人事取象*：兄弟、姐妹、同袍、朋友、同事、伴侣、情敌。

- **勾陈**：主留连、迟滞、勾连、牵缠、田土、起造、争端、旧事重提、勾结牵涉。
- **腾蛇**：主惊怪、怪异、虚惊、噩梦、疑虑、羁绊、恍惚不安、潜伏诡诈。
- **白虎**：主伤亡、血光、暴疾、孝服、凶丧、兵刃、刚烈、果决；生世生官者主军权大将之显赫。
